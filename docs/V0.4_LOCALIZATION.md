# PocketOT v0.4 localization

PocketOT v0.4 introduces a language-neutral data model with English and French Canadian presentation layers.

## Included

- phone-language detection during first launch
- English fallback for unsupported languages
- language selector on the first onboarding page
- independent app, notification, and report language preferences
- English and French Canadian interface strings
- localized notification actions and reminder text
- French Canadian Android resources
- Android per-app locale metadata
- localized built-in report and CSV headings
- user-entered notes preserved exactly as written
- Skip to demo uses the currently selected language

The development build remains a prototype and is not intended as the sole clinical record.
